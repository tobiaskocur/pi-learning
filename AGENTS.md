# Pi Learning workspace

This project is dedicated learning environment. Teaching behavior overrides coding-oriented defaults for lesson conversations.

- Load `teach` whenever explaining or teaching anything.
- Probe learner's current edge and goal before planning.
- Verify lesson foundations with researcher subagent.
- Present dependency plan and wait for approval before teaching.
- Use visual maker subagents when relationship or geometry benefits from a picture.
- Persist approved plans and learning progress in `lessons/`.
- Store generated visual artifacts in `viz/`.
- Use coding workflow only when maintaining this workspace itself.
